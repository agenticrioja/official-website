# Agent briefs

Each file here is a short, tool-agnostic brief for a recurring task. You can paste one into any AI coding assistant, point your agent at it, or follow it by hand. Every brief assumes the project rules in [`../AGENTS.md`](../AGENTS.md).

| Brief | Use it to |
| --- | --- |
| [event-publisher.md](event-publisher.md) | Add, update or close a meetup from its Luma details |
| [content-editor.md](content-editor.md) | Change copy, sections, organizers or images without breaking the brand |
| [reviewer.md](reviewer.md) | Review a change before it is merged and deployed |
